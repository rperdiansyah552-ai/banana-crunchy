# BANANA CRUNCH Marketplace
Website katalog keripik pisang sederhana dengan keranjang dan checkout WhatsApp.

## Ganti nomor WhatsApp
Buka `script.js`, ganti `WHATSAPP_NUMBER` dengan nomor WhatsApp Business dalam format 62 (tanpa + dan tanpa 0 awal).

## GitHub Pages
Unggah semua isi folder ini ke repository GitHub, lalu Settings > Pages > Deploy from a branch > `main` > `/ (root)` > Save.

Catatan: gambar SVG di assets adalah ilustrasi sementara. Ganti dengan foto katalog kelompok Anda jika tersedia. Komposisi dalam modal produk merupakan teks contoh dan harus disesuaikan dengan resep sebenarnya.
